# Inquira

Lead management for B2B ingredient suppliers:
- Brings in inquiries from TradeIndia, IndiaMART (by email) and direct email.
- Deduplicates contacts.
- Keeps an append-only rate book.
- Drafts quotations **as Gmail drafts**. A human always clicks Send.

Claude works alongside the app through a built-in MCP server.
